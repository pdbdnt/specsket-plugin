# An untouched original whose permission expired

Part of [the rules for specific situations](ingestion-conditional-rules.md).

For an untouched generation-zero original whose effective permission expired, follow the [staging recovery](staging-recovery.md) "Untouched original permission renewal" and the capability-and-callability-gated [original permission renewal contract](./product-chunk-permission-renewal.md); running or uncertain originals require reconciliation.
